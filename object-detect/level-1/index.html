Object Detect

Level 1 — Haar Cascade

Hand-designed features (Haar rectangles), a learned classifier (AdaBoost cascade). Face detection.

Done
Approach
OpenCV's built-in pretrained Haar Cascade face detector — the Viola-Jones algorithm, 2001.

Haar wavelets are simple, fixed light/dark rectangular patterns — for example, checking whether a region is darker on top than below, which roughly matches eyebrow-to-cheek contrast. Those rectangle templates are hand-designed, not learned, and there's no neural network here. But the classifier itself is trained: AdaBoost selects which of thousands of candidate rectangle features are actually discriminative and chains them into a cascade of weak classifiers, using labeled face/non-face examples. So this isn't "no learning" — it's hand-designed features plus a learned classifier, the same category as Level 2's HOG+SVM, just with weaker features (raw intensity contrast vs. gradient orientation) and an AdaBoost cascade instead of an SVM.

This is also the pipeline's proof of concept: load an image, run detection, draw a box, save the result. Validating that end-to-end flow on the simplest possible case, before introducing any model weights, gives every later level a debugging baseline — if something breaks in Level 4 or Level 8, the problem is in the new logic, not the load/detect/draw/save loop itself.

face_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_frontalface_default.xml")
faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5, minSize=(30, 30))

Limitations
Stated honestly, not hidden.
  • Single class only (faces)
  • Frontal-face only — fails on tilt, angle, occlusion
  • The features (Haar rectangle templates) are hand-designed, not learned — only the classifier (which features, what cascade order) is trained. A real ceiling relative to Level 3+'s fully learned features.
  • No confidence score in the deep-learning sense
