Object Detect

Level 5 — YOLO-World

Open-vocabulary detection: any object described in plain text at inference time, no training or fine-tuning required.

Done
Approach
Ultralytics YOLOWorld (yolov8s-world.pt) — the direct answer to Level 4's vocabulary gap.

Detects any object described in plain text at inference time — no training or fine-tuning required, unlike COCO's fixed 80-class list.

model = YOLOWorld("yolov8s-world.pt")
model.set_classes(["forklift", "cardboard box", "pallet", "helmet", "person"])
results = model.predict(image_path, conf=0.08, iou=0.5)
Getting there
Worth showing as process, not just the end result.
  • Initial results only found "person" — the default confidence threshold (0.25) was filtering out less-common/compound terms scoring lower; lowering to ~0.08 revealed the rest.
  • "box" matched any box-shaped object — electrical cabinets, mystery equipment — too generic a term. This matches language patterns, not fixed categories.
  • Refined to specific phrases: "cardboard box," "wooden crate," "electrical cabinet," "pallet jack," "safety vest," "helmet."
  • Raising imgsz to 1280 (from the default 640) recovered detection of smaller/distant objects (a pallet jack handle) lost to downscaling, at the cost of needing to re-lower conf since scores shifted slightly.
