Independent Prototype

Pressure Vessel Integrity

A pressure-vessel integrity management prototype combining ML-based corrosion prediction, fleet risk dashboards, and ASME/API standards reference — built end-to-end, from a synthetic 360-vessel fleet through to a Next.js frontend.

Independent prototype built on synthetic data only — explicitly unaffiliated with Phillips 66. The app itself repeats this disclaimer in its own header banner.

Open the app in its own tab · view the source on GitHub.

What's in it

  • ML corrosion prediction — a synthetic fleet of 360 vessels with physics-informed damage mechanisms, scored with a GradientBoosting model server-side and a Ridge model for client-side inference.
  • Fleet risk dashboard — fleet overview, vessel registry, and per-vessel detail pages built in Next.js.
  • Standards grounding — ASME Section VIII formulas and API 510/571/572/579-1/580 inspection logic, mapped to damage mechanisms rather than applying generic ML to a CSV.
Working draft, not for external distribution yet.
