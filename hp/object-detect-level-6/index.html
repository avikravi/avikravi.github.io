Object Detect

Level 6 — Tracking + Unique Counting

Consistent object IDs across frames, so counts reflect unique objects passed through the scene, not repeated per-frame detections.

Priority
Approach
The strongest answer to "counting": tracking assigns each object a persistent ID across frames instead of re-detecting it from scratch every frame.

Per-frame detection counts (Level 5) double-count the same object across many frames as it moves through the scene — a video with 900 frames each showing roughly one part isn't "900 parts," it's one part passing through 900 times. Tracking fixes this by assigning consistent IDs frame-to-frame, so the real answer becomes something like "12 unique parts passed."

Ultralytics has tracking built in — model.track() instead of model() — so this isn't a large lift once Level 5 is working. Worth prioritizing over Level 2 (HOG+SVM) if time is tight, since it's the level that actually answers the counting question.
